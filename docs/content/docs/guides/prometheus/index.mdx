Ferry has its own [Monitoring page](/docs/getting-started/dashboard/server-monitoring). If you already watch your machines with <Term id="prometheus" /> and <Term id="grafana" />, Ferry can be one more machine there, with alerts.

Ferry does not install Prometheus or Grafana. It only publishes its numbers at `/metrics`, in the format of Prometheus.

## The scrape config

```yaml title="prometheus.yml"
scrape_configs:
  - job_name: ferry
    authorization:
      credentials_file: /etc/prometheus/ferry-token
    static_configs:
      - targets: ['127.0.0.1:7878']
```

This config is for a Prometheus on the server of Ferry. The file `ferry-token` has an <Term id="api-token" />.
