Make sure that you have each item before you start.

## The checklist

| Item | Detail |
|---|---|
| A Linux server | A <Term id="virtual-machine" /> is fine. It must have a public <Term id="ip-address" />. |
| Three open ports | Ports 22, 80 and 443 must be open to the internet. If the server has a <Term id="firewall" />, open them there. |
| Docker | Docker Engine with its `docker` CLI and <Term id="buildkit" />. BuildKit is the default builder of current Docker versions. |
| `git` | Ferry runs `docker build` and `git` for the builds. |
| A domain | You must control its <Term id="dns" />. This guide uses `apps.example.com` for the apps. |
| `ferryd` and `ferry` | The two <Term id="binary">binaries</Term>. See [Installation](/docs/getting-started/installation). |

## Get the binaries for the server

On Ubuntu 22.04 or 24.04, or Debian 12 or 13, on x86_64, the [install script](/docs/getting-started/installation/script) installs Docker, git and the two binaries for you.

On another Linux x86_64 server, [download the binaries](/docs/getting-started/installation/download). On ARM64, build them for the <Term id="cpu-architecture" /> of the server, with the dashboard embedded.
