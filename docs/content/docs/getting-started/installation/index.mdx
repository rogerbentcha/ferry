Ferry is one <Term id="rust" /> workspace that builds two <Term id="binary">binaries</Term>.

| Program | Work |
|---|---|
| `ferryd` | The server. One process runs the REST API, the dashboard, the public <Term id="proxy" /> and the engine that builds and runs your apps. |
| `ferry` | The command-line client. It talks to `ferryd` through the REST API. |

The dashboard is a separate React app in `web/`. The build puts it into `ferryd`. Thus you have nothing more to deploy.

## Install with one command

On a fresh Ubuntu or Debian server (x86_64), this command installs Ferry and starts it with <Term id="systemd" />. Then it prints the link that creates your account.

```bash title="Terminal"
curl -fsSL https://github.com/rogerbentcha/ferry/releases/latest/download/install.sh | sudo sh
```

## Download Ferry

On another Linux x86_64 machine, download the two programs from the latest release. You need no build tools.

```bash title="Terminal"
curl -fsSLO https://github.com/rogerbentcha/ferry/releases/latest/download/ferry-x86_64-unknown-linux-gnu.tar.gz
curl -fsSLO https://github.com/rogerbentcha/ferry/releases/latest/download/SHA256SUMS
sha256sum -c --ignore-missing SHA256SUMS
sudo tar -xzf ferry-x86_64-unknown-linux-gnu.tar.gz -C /usr/local/bin ferryd ferry
```

## Build Ferry

On macOS or on ARM64, build the two programs from the source.

```bash title="Terminal"
git clone https://github.com/rogerbentcha/ferry
cd ferry
(cd web && npm ci && npm run build)
cargo build --release
```
